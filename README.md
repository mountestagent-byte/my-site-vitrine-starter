# site-vitrine-starter

Le point de départ de l'atelier Claude Code. Tu pars de cette page volontairement laide,
et tu repars avec ton site en ligne, à tes couleurs.

## Ce qu'il y a dans ce dossier

| Fichier | À quoi ça sert |
|---|---|
| `CLAUDE.md` | La mémoire du projet. Claude Code le lit à chaque session. **C'est là que tu recopies ton design system.** |
| `design-system.md` | La version détaillée du design system, importée par le CLAUDE.md. |
| `PROMPTS.md` | Les prompts de l'atelier, dans l'ordre. |
| `index.html` | La page de départ. C'est elle que tu vas remplacer. |
| `BONUS.md` | Pour ceux qui finissent en avance. |
| `assets/` | Tes images. |

## Démarrer

```bash
cd site-vitrine-starter
claude
```

Puis, dans Claude Code :

```
/init
```

Il va te proposer d'améliorer le `CLAUDE.md` existant. Lis sa proposition avant d'accepter :
c'est le meilleur moment de la séance pour comprendre ce qu'est le contexte.

Ensuite, ouvre `PROMPTS.md` et suis les itérations.

## Publier

Sur GitHub : **Settings → Pages → Source : Deploy from a branch → main / (root) → Save**.

Ton site est en ligne deux minutes plus tard, à l'adresse affichée sur cette page.
